# Gestão Financeira

App de controle financeiro pessoal e da empresa: lançamentos, DRE mensal e anual, inteligência financeira (modelo VAZK), plano de investimentos, vencimentos, cartões, contas, empréstimos, metas, login com senha e relatórios em PDF e Excel.

Funciona direto no navegador e pode ser instalado na tela inicial do celular. Os dados ficam salvos apenas no aparelho de quem usa (localStorage e IndexedDB); nada é enviado para servidor. Faça backup pelo menu Ajustes → Backup e planilha.
