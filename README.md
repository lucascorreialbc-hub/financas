# Gestão Financeira

App de controle financeiro pessoal e da empresa (DRE, vencimentos, cartões, contas, empréstimos, metas e relatórios em PDF).

Funciona direto no navegador e pode ser instalado na tela inicial do celular. Os dados ficam salvos apenas no aparelho de quem usa (localStorage e IndexedDB); nada é enviado para servidor. Faça backup pelo menu Ajustes → Backup e planilha.
